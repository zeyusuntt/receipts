Issue
make the cumulative time counter available to clients The `Bot` object should have an attribute `time` where the cumulative time for the team shown in the GUI is made available. This is useful for example when benchmarking different strategies. There's no way at the moment to programmatically access that value, as far as I could see. Of course the client could time itself, but this has its own pitfalls. So it's better to just make that value available, even if we all know it's not super precise...

Approach
Add a 'time' property to the Bot class that provides access to the cumulative timing information maintained internally by the game engine, likely mirroring functionality seen in existing attributes or methods.

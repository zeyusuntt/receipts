Issue
Add support for providing credentials via environment variables As an alternative to passing user credentials as arguments to `rest_api.get_access_token()`, it would be useful to also have the option of providing these via shell environment variables, for example: ``` export INAT_USERNAME="" export INAT_PASSWORD="" export INAT_APP_ID="" export INAT_APP_SECRET="" ```
Files to edit
  • pyinaturalist/rest_api.py
Approach
Modify the function signature to make all credential arguments optional with default None. Inside the function, replace each None value with the corresponding environment variable, raising an AuthenticationError if any remain missing after checking the environment. This allows calls with zero args (all from env), mixed args/envars (args override), and proper error handling when creds are missing entirely.

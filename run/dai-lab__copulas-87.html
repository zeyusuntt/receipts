Issue
Make vine copulas sample use num_rows arg. Currently the sample method on `copulas.multivariate.vine.VineCopulas` doesn't take in consideration the argument num_rows, would be useful to either delete it, or make it work.
Files to edit
  • copulas/multivariate/vine.py
Approach
Refactor the body of the existing `sample` method into a private helper method `_sample_row(self)` that returns a single sample as a NumPy array. Then modify the public `sample(self, num_rows=1)` method to call `_sample_row` exactly `num_rows` times, collect the results, and return them as a DataFrame with the original column names.

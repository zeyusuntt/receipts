Allow specifying a devicetree binary that is passed to ukify To easily use the dtbs provided with kernel packages allow specifying a devicetree name in mkosi. It can be passed as parameter to ukify. The dtb is typically installed by the kernel package.

Approach
Looking at the error message "TypeError: Config.__init__() got an unexpected keyword argument 'devicetree'", it's clear we need to add a `devicetree` field to the Config class. From the JSON test spec, I can see the expected format includes: "Devicetree": "freescale/imx8mm-verdin-nonwifi-dev.dtb", This matches the pattern used elsewhere in the codebase where fields appear as PascalCase in JSON but snake_case in Python (e.g., "BuildScripts" maps to build_scripts). So I'll add a `devicetree: Optional[Path] = None` field to the Config dataclass in mkosi/config.py. This follows the established pattern shown in other similar optional path fields like linux: Optional[Path] = None. The change should be minimal - just adding the field definition to match what the tests expect.

When using `current_version = "5.06.0"` with `parse = "(?P<major>\d+)\.(?P<minor>\d+)\.(?P<patch>\d+)"` and `serialize = ["{major}.{minor:02}.{patch}"]`, increasing minor would result in `5.70.0` instead of `5.07.0` because the format specifier was applied to string values rather than integers. **Solution:** Modified the `serialize()` function to: 1. Extract format specifiers from the serialization pattern using regex 2. Convert version component values to integers when they have format specs (e.g., `:02`, `:03`) 3.

Issue
Having several start-end tags in included page Having several start-end tags in included page, results in including only the first appearance. Is it possible to have more than one section included? ```markdown <!--start-tag--> ## Important Content1
Files to edit
  • mkdocs_include_markdown_plugin/event.py
Approach
Modify the start/end processing logic in `found_include_tag` and `found_include_markdown_tag` to loop through all start-end pairs instead of stopping after the first one. The loop should: 1) Find the next start tag, 2) Find the next end tag after that start, 3) Extract content between them, 4) Continue from after the end tag. This needs to handle the case where an end tag might not exist after a start tag (extract until end of content).

def _process_start_end_pairs(text, start_tag, end_tag):
    if start_tag is None and end_tag is None:
        return text
    
    result_parts = []
    remaining = text
    
    while True:
        # Find next start tag
        if start_tag is not None:
            start_idx = remaining.find(start_tag)
            if start_idx == -1:
                break
            remaining = remaining[start_idx + len(start_tag):]
        else:
            start_idx = 0
        
        # Find end tag after the start tag
        if end_tag is not None:
            end_idx = remaining.find(end_tag)
            if end_idx == -1:
                result_parts.append(remaining)
                break
            result_parts.append(remaining[:end_idx])
            remaining = remaining[end_idx + len(end_tag):]
        else:
            result_parts.append(remaining)
            break
    
    return ''.join(result_parts)

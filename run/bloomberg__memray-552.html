Issue
`memray run` overwrites `sys.argv[0]` even when `-I` or `-P` is used `memray run` tries to match the updates to `sys.path` that are performed by the interpreter itself when it starts. When those path updates are suppressed (by the `-I` or `-P` command line flags or their corresponding environment variables), Memray's emulation winds up overwriting paths in `sys.path` that needed to be left alone.
Files to edit
  • src/memray/commands/run.py
Approach
Check for presence of isolation flags before modifying sys.argv[0]. If they're present, avoid replacing argv[0] with temporary paths.

Issue
Zero-padded version parts are not working It seems that this fix was removed with some refactoring happened in #112. Tried with version 0.20.1 and the following config parameters: ``` current_version = "5.06.0" parse = "(?P<major>\\d+)\\.(?P<minor>\\d+)\\.(?P<patch>\\d+)" serialize = ["{major}.{minor:02}.{patch}"] search = "{current_version}" replace = "{new_version}"
Files to edit
  • bumpversion/versioning/models.py
Approach
Modify the `__format__` method in the `VersionComponent` class within `bumpversion/versioning/models.py` to ensure it properly handles format specifications such as `:02` for zero-padding. Currently, the method attempts to convert the component's value to an integer before applying the format spec. While this works in simple cases, we hypothesize that under certain conditions — possibly due to how values are stored or retrieved during version manipulation — the value may not be a clean integer string, leading to incorrect formatting. By refining this method to more robustly handle numeric formatting specs while preserving non-numeric values, we aim to fix the zero-padding issue without breaking existing behavior.
